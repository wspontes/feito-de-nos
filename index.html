Não configurado

Para duas pessoas verem os mesmos dados, conectem o site a uma planilha do Google. É gratuito e os dados ficam na sua conta.

Cole aqui a URL gerada ao implantar o Apps Script (passo 4 abaixo)
  1. Crie uma planilha nova no Google Drive (pode chamar Feito de Nós — Dados). Compartilhe com a outra pessoa (Leitura e escrita).
  2. Nela, abra Extensões → Apps Script.
  3. Apague o código que já estiver lá e cole o arquivo backend-apps-script.js (está no GitHub do projeto) ou o código abaixo.
  4. Clique em Deploy → Nova implantação. Tipo: Aplicativo da Web. Executar como: Eu. Quem tem acesso: Qualquer pessoa. Copie a URL gerada.
  5. Cole a URL acima e clique em Salvar e conectar. Pronto — os dois aparelhos passam a ver os mesmos dados.
